# Arogya-Q

Hybrid Quantum-Classical Machine Learning Platform for Early Disease Detection

**Team:** Black Hole  
**Event:** Smart India Hackathon (SIH) 2026  
**PS ID:** SIH26139  
**Theme:** Med Tech / Bio Tech / Health Tech

## About
Arogya-Q is a hybrid quantum-classical ML platform designed for early disease 
detection, with a focus on rural healthcare accessibility. The system 
auto-benchmarks classical and quantum models (Random Forest/SVM, QSVM, VQC) 
to select the best-performing approach for a given dataset.

## Folder Structure
- `data/` — datasets
- `classical_ml/` — classical models (Random Forest, SVM)
- `quantum_ml/` — quantum models (QSVM, VQC)
- `auto_selector/` — model auto-selection + explainability
- `backend/` — API and security
- `frontend/` — dashboard/UI
- `docs/` — documentation
